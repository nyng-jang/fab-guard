# 0013. 분석글 AI는 바꿔 끼울 수 있게, 기본값은 Gemini

- 상태: 확정 (2026-11-10 나영 선택)
- 날짜: 2026-11-10

## 맥락
ADR 0007과 0010은 분석글을 Claude API로 쓰기로 했습니다. 나영이 Google Gemini API로 써도 되는지 물었습니다. 분석글 단계는 탐지기가 만든 근거 묶음(`results/detector_v1/alerts.json`)을 받아 글만 쓰므로, 어떤 AI를 쓰든 탐지기와 채점은 바뀌지 않습니다.

## 결정
- 분석글 스크립트에 AI 호출을 감싸는 작은 연결부를 두고, 제공자(gemini / claude)와 모델 이름은 설정(환경 변수)으로 고릅니다.
- 기본값은 Gemini입니다.
- 프롬프트, 근거 묶음, "근거가 없으면 '원인 불명'" 규칙, 분석글 채점은 제공자와 상관없이 같습니다.
- API 키는 저장소에 넣지 않고 환경 변수로만 받습니다.

## 이유
- 개인 포트폴리오라 무료 한도가 있는 Gemini가 비용 부담이 적습니다.
- 면접에서 보여줄 핵심("근거 없을 때 '원인 불명'이라고 쓰는가")은 모델보다 프롬프트와 채점으로 지키는 부분이라, 제공자를 바꿔도 같은 기준으로 검증할 수 있습니다.
- 바꿔 끼울 수 있으면 두 모델의 분석글을 같은 채점으로 비교할 수 있습니다.

## 검토한 대안
- Gemini만: 가장 단순하지만 비교가 불가능하고, 바꿀 때 코드를 고쳐야 함
- Claude 그대로: 원래 계획이지만 비용이 듦

## 결과
- ADR 0007의 "분석글·리포트 초안: Claude API"와 ADR 0010의 "Claude API 분석글"은 이 ADR로 대체합니다(나머지 결정은 유지).
- ADR 0003(외부 AI 사용)은 그대로 적용됩니다. Gemini API 무료 등급은 약관상 입력이 서비스 개선에 쓰일 수 있으니, 합성·공개 데이터만 넣고 실제 공장 데이터는 넣지 않습니다. 시작 전에 최신 약관을 확인합니다.
- 모델 이름은 코드에 박지 않고 설정으로 둡니다. 모델이 바뀌어도 분석글 채점을 다시 돌려 비교합니다.
