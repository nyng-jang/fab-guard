# 0016. 화면 디자인은 docs/design/DESIGN.md를 따름

- 상태: 확정
- 날짜: 2026-11-18

## 맥락
목업은 처음에 plush-ui 스타일(큰 라운드, 초록 그라데이션)로 만들었고, 나영이 디자인 기준으로 DESIGN.md(Seline Analytics 스타일)를 주었습니다.

## 결정
- 화면(목업, 정적 결과 페이지)은 [docs/design/DESIGN.md](../design/DESIGN.md)를 따릅니다: 따뜻한 스톤 배경(#fafaf9), 흰 카드와 1px 헤어라인, 단 하나의 강조색 시안(#3ba6f1), 알약 버튼, 굵지 않은(400) 제목.
- 한글 글꼴은 Inter 계열에 Noto Sans KR을 섞어 씁니다(Roobert 대체로 Inter Tight).
- 등급은 색을 늘리지 않고 모양과 채움으로 구분합니다: 긴급 ▲ 검정 채움, 주의 ● 테두리, 센서 의심 ■ 회색, 수신 오류 점선. 차트에서 관리 한계를 벗어난 점은 시안.
- DESIGN.md가 라이트 테마 전용이라 다크 모드는 두지 않습니다.

## 이유
DESIGN.md는 "강조색은 시안 하나, 빨강·초록 추가 금지"를 규칙으로 둡니다. 산업 HMI 원칙도 색에만 기대지 않는 표시(모양 + 글자)를 권하므로 두 원칙이 함께 성립합니다.

## 검토한 대안
- 긴급만 빨강 유지: 눈에 더 잘 띄지만 DESIGN.md 규칙과 충돌. 실사용 피드백에서 긴급이 묻힌다는 말이 나오면 다시 봄
- plush-ui 스타일 유지: 디자인 기준이 바뀌어 대체

## 결과
- 목업: [mockup/wafer-alert-center.html](../../mockup/wafer-alert-center.html)
- plush-ui에서 가져온 상호작용(토스트 되돌리기, 단계 표시, 남은 시간 링, 펼치는 근거)은 DESIGN.md 색·모양으로 바꿔 유지합니다.
