# 0005. 알림은 메일, 미확인 1시간 후 이관

- 상태: 확정
- 날짜: 2026-11-10

## 맥락
이상이 생기면 담당자에게 알려야 하고, 긴급인데 아무도 확인하지 않으면 다른 담당자에게 넘겨야 합니다.

## 결정
- 알림 채널은 메일입니다(Resend 같은 발송 서비스). 슬랙 웹훅은 나중에 선택으로 추가합니다.
- 메일 속 "확인" 링크로 확인 여부를 기록합니다.
- 긴급 알림을 1시간 동안 확인하지 않으면 다음 담당자에게 이관합니다.
- 긴급/주의 기준은 원본 데이터를 먼저 돌려 본 뒤 정합니다(TODO 참고).

## 이유
메일은 계정 연동 없이 바로 쓸 수 있고 기록이 남습니다. 1시간은 매시간 수집 주기와 맞습니다.

## 검토한 대안
- 슬랙 우선: 워크스페이스 설정이 필요해 첫 버전에서는 뒤로 미룸
- 카카오·팀즈: 포트폴리오 데모에서는 설정 부담이 큼

## 결과
이관 대상 담당자 목록은 로그인 없이 설정 파일이나 DB 테이블로 관리합니다(0006 참고).
