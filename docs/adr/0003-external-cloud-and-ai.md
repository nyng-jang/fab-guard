# 0003. 외부 클라우드·AI 사용

- 상태: 확정
- 날짜: 2026-11-10

## 맥락
실제 공정 데이터는 보통 외부 반출이 금지되지만, 이 프로젝트는 개인 포트폴리오이고 합성·공개 데이터만 씁니다.

## 결정
Supabase, Vercel 같은 외부 클라우드와 Claude API 같은 외부 AI를 사용합니다. README에 "실제 공장에 적용하려면 사내 서버로 옮겨야 한다"고 적습니다.

## 이유
기밀 데이터가 없으므로 보안 위험이 없고, 관리형 서비스를 쓰면 혼자서도 빠르게 동작하는 데모를 만들 수 있습니다.

## 검토한 대안
- 처음부터 사내형(온프레미스) 구성: 포트폴리오 단계에서는 운영 부담만 커짐

## 결과
AI 호출 부분은 나중에 사내 모델로 바꿀 수 있도록 한 곳에 모아 둡니다.
