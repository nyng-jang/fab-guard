# 0004. 생성형 AI는 분석글과 리포트 초안에만 사용

- 상태: 확정
- 날짜: 2026-11-10

## 맥락
설계 원칙은 "판정은 가볍게, 글쓰기는 AI로, 최종 판단은 사람이"입니다. AI가 숫자를 지어내거나 판정을 흔들면 신뢰할 수 없습니다.

## 결정
- 이상 판정, 등급 분류, 근거 수집은 Python 규칙과 통계·가벼운 모델로 합니다.
- 생성형 AI는 6단계 분석글과 9단계 리포트 초안에만 씁니다.
- AI에는 시스템이 계산해 고른 근거만 넘기고, 원인은 "후보"로, 후보마다 근거를 붙이게 합니다. 근거가 없으면 "원인 불명"이라고 쓰게 합니다.

## 이유
정확도, 비용, 재현성 때문입니다. 판정은 같은 입력에 같은 결과가 나와야 하고, 전체 데이터를 AI에 넘기는 것은 비싸고 부정확합니다.

## 검토한 대안
- AI가 이상 판정까지 하기: 재현성이 없고 오탐·미탐 원인을 설명하기 어려움

## 결과
더미데이터 E6(원인 불명 결함)으로 AI가 근거 없을 때 원인을 지어내지 않는지 시험합니다.
