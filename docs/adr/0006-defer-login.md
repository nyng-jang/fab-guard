# 0006. 로그인 보류

- 상태: 확정
- 날짜: 2026-11-10

## 맥락
담당자 화면에 로그인을 붙이면 권한, 장비별 담당자 배정까지 범위가 커집니다.

## 결정
첫 버전에서는 로그인을 만들지 않습니다. 담당자와 이관 순서는 설정으로 관리합니다.

## 이유
핵심은 탐지, 분석, 알림 흐름입니다. 로그인은 포트폴리오 가치에 비해 시간이 많이 듭니다.

## 검토한 대안
- Supabase Auth로 바로 구현: 빠르긴 하지만 권한 설계까지 따라옴

## 결과
데모 화면은 공개 링크로 두고, 쓰기 동작(승인, 피드백)은 메일 링크의 일회용 토큰 정도로 막습니다. 나중에 필요하면 Supabase Auth로 추가합니다.
