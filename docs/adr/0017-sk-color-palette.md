# 0017. 화면 색은 SK 색상 체계로 다시 구성

- 상태: 확정
- 날짜: 2026-11-18
- 대체: [0016](0016-ui-design-system.md)의 색상 부분만 (배경·카드·글꼴·모양·라이트 전용은 0016과 DESIGN.md 그대로)

## 맥락
0016에서는 DESIGN.md를 따라 강조색을 시안 하나로 두었습니다. 나영이 SK 주요 색상(SK Red, SK Orange)과 보조 색상(Yellow, Green, Teal, Blue, Navy, Purple, Black, White) 조합으로 색을 다시 짜 달라고 했습니다.

## 결정
색마다 역할을 하나씩 정해, 같은 색이 화면 곳곳에서 다른 뜻으로 쓰이지 않게 합니다.

| 역할 | 색 | 쓰는 곳 |
|---|---|---|
| 행동, 긴급 | SK Red #EA002C | 주 버튼, 로고, 알림 배지, 긴급 등급(배지 글자는 대비를 위해 #d10027) |
| 평소와 다른 데이터 | SK Orange #F47725 | 히트맵 칸(진할수록 많이 다름), 차트에서 알림 대상 점 |
| 정상, 완료 | SK Teal #009A93 | 차트의 평소 범위 띠와 선, 확인함·승인 완료 표시, 처리 현황 막대 |
| 안내 | SK Blue #0072C6 | 안내 배너, 원인 후보 가능성 막대 |
| 선택, 어두운 면 | SK Navy #0E306D | 선택된 칩·탭, 토글 켜짐, 토스트, 툴팁, 포커스 테두리 |
| 주의 | SK Yellow #FBBC05 계열 | 주의 등급 배지(글자는 대비를 위해 진한 호박 #8a6100) |
| 센서 의심 | SK Purple #68127A | 센서 의심 등급 배지 |

- SK Green은 흰 배경 위 글자·선 대비가 낮아(약 1.9:1) 지금은 쓰지 않습니다.
- 흰 글자를 올리는 버튼은 SK Orange(대비 약 2.9:1, 기준 4.5:1 미달) 대신 SK Red(약 4.6:1)로 합니다.
- 등급은 여전히 색만으로 구분하지 않고 모양(▲ ● ■ 점선)과 글자를 함께 씁니다.

## 결과
- 목업 `mockup/wafer-alert-center.html`의 `:root` 색 토큰을 이 표대로 바꿨습니다.
- 개인 포트폴리오 화면이라 SK 이름이나 로고는 넣지 않고 색 체계만 따릅니다.
