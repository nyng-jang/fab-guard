# 0008. 평소 기준: 앞 25로트, 공정 값 공통·계측 값 노드별

- 상태: 확정
- 날짜: 2026-11-10

## 맥락
이상의 크기(σ 배수)와 탐지 기준 모두 "평소"를 어떻게 정의하느냐에 달려 있습니다. 원본을 보면 공정 값 9개는 기술 노드와 상관없이 같은 분포지만, critical_dimension, vth, oxide_thickness, yield는 노드마다 수준이 크게 다릅니다(예: CD 7nm 약 18, 14nm 이상 약 28).

## 결정
- 평소 기준 구간은 앞 25로트(2023-01-01 ~ 01-25)입니다.
- 공정 값 9개의 평균·σ는 이 구간 전체에서 구합니다.
- 계측 값 9개와 yield의 평균·σ는 기술 노드별로 구합니다.
- 더미데이터 주입과 점검 스크립트가 같은 정의를 씁니다.

## 이유
노드를 무시하면 7nm 웨이퍼는 늘 CD가 "낮은 이상"으로 보이고, 노드별로 나누면 이 착시가 사라집니다. 공정 값까지 노드별로 나누면 표본만 줄어듭니다.

## 검토한 대안
- 모든 값을 노드별로: 공정 값은 노드와 무관해 표본만 줄어듦
- 모든 값을 공통으로: 노드 차이가 이상처럼 보임
- 장비별 기준: 장비마다 로트가 2~8개뿐이라 너무 적음

## 결과
깨끗한 구간에 7nm 로트는 1개(LOT_0020), 22nm 로트는 2개뿐이라 이 노드의 기준은 불안정합니다. 실제 탐지기에서는 노드 표본이 적으면 전체 기준으로 물러나는 규칙을 검토합니다.
